# 서울시 분리배출 안내 Knowledge Agent

“서대문구인데 생활쓰레기를 언제 내놓나요?” 안내 담당자가 이 질문을 받으면 품목을 확인하고, 구청 원문을 찾아 동·주택 유형·적용 기간까지 대조해야 합니다. 이 프로젝트의 목표는 **담당자가 어떤 근거로 안내했는지 다시 확인할 수 있고, 조건이 부족하면 필요한 정보만 되묻는 것**입니다. 현재 공유하는 내용은 개발 계획, 팀 계약, CI 설정입니다.

## 팀원은 이렇게 시작합니다

| 시점 | 읽을 문서 | 읽고 할 일 |
| --- | --- | --- |
| 작업을 고르기 전 | [해결할 문제와 과제 평가 기준](docs/problem.md) | 사용자 질문 하나를 골라 어떤 원문이면 답할 수 있는지, 어느 조건에서는 보류할지 설명합니다. |
| 당일 작업을 정할 때 | [4일 팀 로드맵](ROADMAP.md) | 내 담당 행에서 오늘 넘길 산출물과 받는 사람을 확인합니다. 수업의 5일차 재현·발표 준비도 확인합니다. |
| 다른 모듈과 연결할 때 | [팀 개발 환경과 API 계약](docs/TEAM-SETUP.md) | 같은 예시 요청·응답으로 먼저 개발하고, 실제 검색 결과를 연결한 뒤 청크 ID와 원문 위치를 대조합니다. |
| 테스트와 PR을 준비할 때 | [Codecov·Dependabot 가이드](docs/CI-AND-DEPENDENCIES.md) | 언어별 테스트 실행 경로와 의존성 변경을 확인합니다. 검색 성능과 답변 정확도는 고정 평가셋으로 별도 측정합니다. |
